# GCC-ToolChain
Set of GCC related tools, similar to https://github.com/alisw/gcc-toolchain/
but containing different versions of GCC, currently GCC 16.2, 14.4, 13.2,
12.3, 11.5. Also autoconf-archive has been removed (moved to the project
autotools since it is more proper place).
